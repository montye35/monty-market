# Monty Market

واجهة متجر إلكتروني عربية لملابس رجالية كاجوال، مصممة باتجاه RTL وبألوان العلامة.

## تشغيل المشروع

افتح `index.html` مباشرةً في المتصفح. لا يحتاج المشروع إلى تثبيت حزم أو تشغيل خادم.

## الوظائف الحالية

- تصفح منتجات التيشيرتات والبحث عنها وتصفيتها.
- إضافة المنتجات إلى السلة وتعديل الكميات.
- عرض معلومات التواصل للشكاوى والحجز عبر واتساب.

صور المنتجات الحالية مؤقتة، والدفع والاشتراك غير مربوطين بخدمات فعلية.
