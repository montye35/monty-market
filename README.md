# Monté

واجهة متجر إلكتروني عربية لملابس رجالية كاجوال، مصممة باتجاه RTL وبألوان العلامة.

## تشغيل المشروع

افتح `index.html` مباشرةً في المتصفح. لا يحتاج المشروع إلى تثبيت حزم أو تشغيل خادم.

## الوظائف الحالية

- تصفح منتجات التيشيرتات والبحث عنها وتصفيتها.
- عرض صورة مستقلة لكل منتج، مع اختيار صور الألوان لتيشيرت القَصّة الواسعة.
- فتح صفحة تفاصيل لكل تيشيرت تعرض الوصف والخامة والمقاسات.
- إضافة المنتجات إلى السلة من صفحة المتجر أو صفحة التفاصيل، مع حفظ السلة بين الصفحتين.
- تعديل كميات المنتجات وإزالتها من السلة.
- إضافة رسوم توصيل ٤٥ جنيهًا إلى إجمالي الطلب.
- إرسال تفاصيل الطلب وروابط المنتجات إلى واتساب عند إتمام الطلب.
- عرض معلومات التواصل للشكاوى والحجز عبر واتساب.

## إضافة صور المنتجات

ضع صورة كل منتج داخل `assets/products/` بالأسماء التالية:

| اسم الصورة | المنتج |
| --- | --- |
| `product-01.jpg` | تيشيرت Monté الأساسي |
| `product-02.jpg` | تيشيرت قَصّة واسعة |
| `product-03.jpg` | تيشيرت خط المدينة |
| `product-04.jpg` | تيشيرت يوم هادي |
| `product-05.jpg` | تيشيرت أوفر سايز |
| `product-06.jpg` | تيشيرت Monté ستوديو |
| `product-07.jpg` | تيشيرت قطن يومي |
| `product-08.jpg` | تيشيرت شكل جديد |

لتيشيرت القَصّة الواسعة، أضف صور الألوان بالأسماء `product-02.jpg` و`product-02-3.jpg` و`product-02-4.jpg`. الصور تظهر كاختيارات في بطاقة المنتج وصفحته، ويؤدي اختيارها إلى تغيير الصورة. اختيار لون من البطاقة يفتح صفحة التفاصيل على اللون نفسه. أسماء الاختيارات حاليًا «اللون الأول» إلى «اللون الثالث»، ويمكن تعديلها في قائمة `variants` داخل `products.js`.

صفحة تيشيرت Monté الأساسي تعرض اختيارات الأبيض والزيتوني والكحلي. لتغيير صور المعاينة لهذه الألوان، أضف صورًا منفصلة للمنتج واربطها في `products.js`.

تقدر تستخدم صور `JPG` أو `PNG` أو `WebP`؛ لو اخترت امتدادًا غير `JPG`، غيّر اسم الصورة المقابل في `products.js` أيضًا. يُفضّل أن تكون كل الصور بنفس الأبعاد وباتجاه رأسي.

## تفاصيل الخامة والمقاسات

بيانات كل منتج موجودة في `products.js`. املأ الحقول `description` و`material` و`sizes` لكل تيشيرت لعرض مواصفاته في صفحة التفاصيل. مثال لشكل المقاسات: `sizes: ["S", "M", "L", "XL"]`. ترك المقاسات فارغة يعرض تنبيهًا بأنها لم تُحدّد بعد بدل اختلاق مقاسات.

الدفع والاشتراك غير مربوطين بخدمات فعلية.

لإتمام الطلب مع روابط منتجات قابلة للفتح، انشر المتجر على رابط عام يعمل عبر `HTTP` أو `HTTPS`. زر إتمام الطلب يجهّز رسالة واتساب إلى `01280135908` تشمل المنتجات والكميات والألوان والأسعار وروابط صفحاتها، ويطلب من العميل تحديد المقاس عبر المحادثة. لا تُفتح روابط الطلب من نسخة `file://` المحلية لأنها غير متاحة للعميل.
